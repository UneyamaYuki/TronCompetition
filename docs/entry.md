# 相互守護（ミューチュアル・ケア）アクアリウム
～ 孤独死防止共生システム ～

![コンセプトアート](Gemini_Generated_Image_ocufsrocufsrocuf.png)



##　概要説明

孤独死という社会課題に対し、人と魚が互いを守り合う「相互守護」をコンセプトとしたアクアリウムシステムです。
本システムは、**人が魚を守り、その行為が人自身の安全を守る**という双方向の共生関係を技術的に実現します。

- **人 → 魚（ケア）：** 飼育者が日常的に行う給餌や水槽の清掃といった飼育行動が、魚の健康と生命を維持します。
- **魚 → 人（見守り）：** システムが飼育者の日常的な飼育行動を多角的に検知・記録し、その行動パターンの変化や途絶から飼育者自身の安否を推定します。

μT-Kernel 3.0 のリアルタイムタスク管理により、飼育行動の監視と水槽環境の制御を並行して確実に実行。飼育者の活動が途絶えた際には異変の可能性があると判断し、外部へ速やかに助けを求めます。これにより、共生を通じた自然な安否確認と、飼育者・魚双方の生活の質の向上を両立するシステムを構築します。

## 機能説明

### プロダクト形態

本システムは、**汎用的な水槽の縁にクリップで装着するだけで利用を開始できる単体デバイス**です。特別な工事や水槽の改造は不要で、既存のアクアリウム環境にそのまま導入できます。

#### 魚と水槽の状態から飼育行動を読み取る

カメラは人を映すのではなく、**水槽の中に向けます**。観察対象はあくまで魚と水槽の様子です。飼育者本人を撮影しないので、監視されているという心理的な圧迫感がありません。

具体的には、EK-RA8P1 搭載の Ethos-U55 NPU とCortex-M85上で軽量な画像処理を動かし、水槽内の映像から給餌行動を検出します。メインアプリはμT-Kernel 3.0上で動作し、カメラ取得から判定、LCDへのデバッグ・給餌・未給餌アラート表示まで実機上で完結します。PCは実運用の検出経路に含めません。

- **魚の摂餌行動：** 沈下式のエサが投入されると、画像差分からエサ候補の下向きの軌跡を追跡できます。1匹の金魚ボックスがエサ候補へ近づき、金魚とエサが互いに近づく方向で重なった場合、または金魚の近傍でエサ候補が消失した後に一定時間再出現しなければ、給餌完了と判断します。

水の濁り、水面の揺れ、水槽内レイアウトの変化は将来の拡張候補であり、現在の給餌検出モデルの対象外です。

検出結果は「最後に飼育行動が確認された時刻」として記録し、そこからどれだけ時間が空いたかで飼育者の活動状況を追跡します。

ただし、画像だけではエサが魚に隠れた場合や底砂に残った場合を完全には区別できません。そのため、餌候補の沈下、金魚ボックスへの接近、近傍での消失、消失後の非再出現を状態機械で確認し、判定できない場合は `unknown` として扱います。画像以外のセンサーは使用しません。

#### 異変時に外部へ助けを求める

飼育行動の途絶は、最後に確認した給餌完了から3日間（テスト時は10分間）経過した場合に検知し、まずLCDにアラートを表示します。Wi-Fi / BLE 通信モジュールを通じた連絡先への外部通知は将来拡張とし、今回のメインアプリ実装対象には含めません。


## 応募プログラムのアピールポイント

- **独創性：** 既存の「監視カメラ」とは異なり、生体への「ケア」を安否確認のトリガーとする、心理的負担の少ない「相互守護」モデル。
- **技術的挑戦：** 高性能な Arm Cortex-M85 と Ethos-U55 NPU を、μT-Kernel 3.0 のリアルタイム環境下で統合。エッジ側で解析を完結させることで、プライバシー保護と即時性を両立。
- **信頼性：** RTOS を採用することで、複雑な AI 解析を行いながらも、水槽の生命維持という「止めてはいけない制御」を確実に担保する設計。

## 応募者のアピールポイント

監視カメラで見張るのではなく、魚の世話という日々の営みの中に、さりげなく安否確認を組み込めたら。そう思ったのがこのシステムの出発点です。

RA8P1 の Ethos-U55 NPU というハードウェアを最大限に活用しつつ、μT-Kernel 3.0 のリアルタイム環境で動かすのは正直かなりの挑戦ですが、だからこそやる意味があると思っています。「便利な道具」ではなく「命に関わるシステム」を作る以上、RTOS のタスク管理や割込み制御といった基礎を手を抜かずにやり切ります。
